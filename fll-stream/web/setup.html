Bitfocus Companion

When something happens here, this server can press a Companion button. Enter the Companion computer's address and, for each event, the button location as page/row/column (for example 1/0/3). Leave a box empty for no trigger. Save first, then use Test to press that button once.

To control this app from Companion, use its Generic HTTP module and send a POST (no body needed) to http://THIS-PC:8090/api/do/start. Available: start, abort, next, prev, post_last (show the scores of the last played match), unpost (hide scores).

Import schedule

Open the event's schedule page on fll.nexus, select the whole Robot game table, copy, and paste it here. Team names: copy the team list from the event's main page. Leave a box empty to keep what is loaded. Importing a schedule jumps back to the first match.
